# Contributing to Dependable Machine Learning

Thanks for your interest in improving Dependable Machine Learning. Contributions of
all sizes are welcome — fixing typos, clarifying explanations, adding examples,
or writing new sections.

## How to contribute

1. Open an issue first for anything larger than a small fix, so we can agree on
   scope before you invest time.
2. Fork the repository and create a branch for your change.
3. Open a pull request. A preview of the rendered book is built automatically
   for each PR.
4. In the pull request, confirm that you agree to the Contributor License
   Agreement below (the pull request template includes a checkbox for this).
